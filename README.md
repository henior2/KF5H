## Summary

This is our submission for the [Gry wektorowe](https://science-cup.pl/wp-content/uploads/2023/11/MSC4_2023_Gry_wektorowe.pdf) task of the Motorola Science Cup 2023/24 contest.

The task required us to recreate 3 retro Atari games: _Asteroids (1979)_, _Battlezone (1980)_, and _Tempest (1981)_ in a **custom-made graphics engine**.
